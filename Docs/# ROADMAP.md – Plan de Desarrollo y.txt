# ROADMAP.md – Plan de Desarrollo y Fases del Proyecto

## 1. Visión General
Este documento traza la ruta de ejecución para construir la Plataforma de Educación Financiera. El desarrollo se divide en fases iterativas para validar rápidamente la propuesta pedagógica antes de expandir el producto.

---

## 2. Fases de Desarrollo

Fase 1: Fundamentos ➔ Fase 2: Motor IA ➔ Fase 3: App Web ➔ Fase 4: Experiencia ➔ Fase 5: Expansión

Objetivo: Organizar el aprendizaje en lecciones estructuradas con seguimiento de progreso.

🟢 Fase 6: Optimización y Lanzamiento — Completada
Objetivo: Preparar el sistema para uso público y escala.

[x] Medición de métricas de éxito — registro simple de eventos (analytics_events, migración 005): lesson_completed y quiz_completed (con puntaje) para medir la tasa de finalización.
